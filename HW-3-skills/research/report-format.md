# Research memo format

```markdown
# <Question in one line>

- Date: <ISO date>
- Status: answered | partial
- Project version pins: <package@version, or "not applicable">

## Verdict

One short paragraph. What to do with this.

## Findings

### <Sub-question or topic>

Fact. (Source: <url or path>)

Inference, labelled as such.

## Conflicts

Where sources disagree, with which you trust.

## Open questions

- What is still unknown, and what source would settle it

## Sources

1. <full URL or repo path> — why it was used
```
